# プログラム編成システム

`abstract.xlsx` の1枚目にある演題一覧を読み込み、Django 管理画面でプログラムを編成します。

## 起動

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py createsuperuser
.venv/bin/python manage.py runserver
```

管理画面は `http://127.0.0.1:8000/admin/`、タイムテーブルの年会一覧は `http://127.0.0.1:8000/`、年会別の編成画面への入口は `http://127.0.0.1:8000/organize/` です。編成画面には管理画面の権限が必要です。

## 操作

1. 管理画面の「年会情報」で年会名、略称、会期の開始日・終了日、会場を登録します。略称は編成画面のURLに使われ、例えば `PASJ2026` なら `/organize/PASJ2026/` です。既存の年会には移行時に `meeting-<ID>` 形式の略称が設定されます。必要に応じて変更してください。
2. 管理画面の「演題」→「アブストラクトをインポート」で `abstract.xlsx` をアップロードします。
3. 管理画面の「部屋」で、部屋名と所属する年会を登録します。同じ部屋名を別の年会で使えます。
4. `/organize/` の年会一覧から編成画面を開き、セッションを作成します。その年会のセッションと会期内の日付候補が表示されます。管理画面からもセッションを作成できます。セッションコード、開始時刻、1講演あたりの時間（分）、セッションの部屋を設定します。終了時刻は、割り当てられた発表予定の講演数から自動計算されます。講演がない場合は空欄です。
   年会が未設定の既存セッションがある場合は、年会一覧の「年会未設定のセッション」から確認できます。年会への割り当ては管理画面で行います。
5. 未割り当ての演題カードをセッションの枠へドラッグします。枠内で並び替えたり、未割り当てへ戻したりできます。移動ごとに保存されます。
   セッションコードが `FRO` の場合、発表予定の演題には並び順に `FRO01`、`FRO02`…というプログラム番号が自動で付きます。並び替え、移動、取り消し、セッションコード変更の際も再採番されます。セッションコードは重複できません。コードを設定していないセッションでは手動のプログラム番号を使えます。
6. 「演題」で発表開始・終了時刻を設定します。セッションコードがない場合はプログラム番号を手動で設定できます。部屋はセッションの部屋を引き継ぎ、演題ごとに上書きできます。
7. 発表取り消しは演題の「状態」を変更します。セッションに割り当て済みの演題は、編成画面とタイムテーブルに取り消し線付きで残り、プログラム番号と講演時間も保持します。

## タイムテーブル

年会別の `/timetable/<略称>/` に、Excelのように日付を横並びにし、各日で部屋ごとの時間割を表示します。横幅に収まらない場合は横スクロールできます。セッションの開始・終了時刻、名称、コード、プログラム番号の範囲を確認でき、時間枠を選ぶと下の演題一覧が開きます。演題ごとの時刻が未入力なら、セッション開始時刻と1講演あたりの時間から表示時刻を計算します。会期内のセッション情報を更新すると、ページの再読み込みでタイムテーブルにも反映されます。

画面上部の「Excelを出力」から、登録済みのタイムテーブル情報を `.xlsx` ファイルとしてダウンロードできます。日程シートでは日付を最大3日ずつ横並びにし、5分刻みの時刻・部屋・セッション枠・プログラム番号を掲載します。「演題一覧」シートには各講演の情報を載せ、日時未設定のセッションがあれば別シートにまとめます。出力ファイルは出力時点のデータから生成されます。

セッションの変更権限がある管理者は、タイムテーブル上のセッションカードを別の日・部屋の列へドラッグして日付、部屋、開始時刻を変更できます。開始時刻は5分刻みです。セッションの長さは維持され、終了時刻と個別に設定済みの演題時刻も同じ分だけ移動します。会期外の日付には移動できません。

休憩や式典など演題のない枠は、セッション作成時に任意の「講演なしの枠の長さ（分）」を設定すると終了時刻まで表示できます。日付や開始時刻が未設定のセッションは、タイムテーブル下部にまとめて表示します。

管理画面の「演題」にある著者の入力欄と、折りたたまれた「元データの著者表記」は別々に保存されます。著者の名前や所属を編集しても、`<sup>` などのタグを含む元データの文字列は自動更新されません。元データの文字列を変える場合は、その欄を直接編集してください。

再インポートでは演題登録番号で同一演題を判定し、Excel由来の演題・著者情報を更新します。管理画面で修正した著者欄と元データ欄も、再インポート時にExcelの内容で上書きされます。編成情報、状態、メモは保持します。Excelに存在しなくなった演題は削除しません。

本番運用時は `DJANGO_SECRET_KEY`、`DJANGO_DEBUG=0`、`DJANGO_ALLOWED_HOSTS` を設定してください。Excelには個人情報が含まれるため、管理画面のアカウントとファイルの保管に注意してください。
